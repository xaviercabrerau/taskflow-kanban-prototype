QUICK START
───────────────────────────────────────────────────────────────────────────
  ./2-health-check-utils.sh              Full health check
  ./2-health-check-utils.sh watch        Continuous monitoring (30s intervals)
  ./2-health-check-utils.sh json         JSON output for integrations
  ./2-health-check-utils.sh --help       Show help text

ENVIRONMENT SETUP
───────────────────────────────────────────────────────────────────────────
  export REDIS_URL="redis://:password@host:6379"
  export SUPABASE_URL="https://project.supabase.co"
  export SUPABASE_ANON_KEY="key"
  export GMAIL_SERVICE_ACCOUNT="/path/to/service-account.json"
  export GOOGLE_CLOUD_PROJECT="gcp-project-id"
  export PUBSUB_TOPIC="projects/project/topics/name"

HEALTH CHECKS (8 Components)
───────────────────────────────────────────────────────────────────────────
  1. Redis               Connection, latency, memory, clients
  2. Supabase            API connectivity, database queries, tables
  3. Gmail API           Service account validation, scopes, credentials
  4. Google Pub/Sub      Topic existence, subscriptions, message lag
  5. BullMQ Queue        Depth, failed jobs, processing rate
  6. Notifications DB    Query latency, table stats, record counts
  7. API Endpoints       /api/health response, JWT validation
  8. Error Rate          System-wide error aggregation, alerting

EXIT CODES
───────────────────────────────────────────────────────────────────────────
  0 = Healthy           All systems operational
  1 = Warning           Operational but with degradation
  2 = Critical          One or more services unavailable

CRON JOBS
───────────────────────────────────────────────────────────────────────────
  # Daily check at 2 AM
  0 2 * * * /path/to/2-health-check-utils.sh >> /var/log/taskflow-health.log 2>&1

  # Hourly check
  0 * * * * /path/to/2-health-check-utils.sh >> /var/log/taskflow-health.log 2>&1

  # Every 5 minutes with alerts
  */5 * * * * if ! /path/to/2-health-check-utils.sh >/dev/null 2>&1; then \
    mail -s "TaskFlow Alert" ops@example.com </var/log/taskflow-health.log; fi

TROUBLESHOOTING
───────────────────────────────────────────────────────────────────────────
  Error                           Fix
  ──────────────────────────────────────────────────────────────────────
  Command not found (redis-cli)   Install: brew install redis / apt-get install redis-tools
  Bash compatibility error        Run: bash ./2-health-check-utils.sh
  Connection timeout              Check network: ping host, curl -I https://api
  Missing env vars                Load: source .env.local
  Permission denied               Run: chmod +x 2-health-check-utils.sh
  JSON parse error                Install jq: brew install jq

COLOR INDICATORS
───────────────────────────────────────────────────────────────────────────
  ✓ Green   = Healthy, responsive, within thresholds
  ⚠ Yellow  = Operational but slow/degraded, approaching limits
  ✗ Red     = Critical, unavailable, exceeding limits
  ℹ Blue    = Informational, status update
